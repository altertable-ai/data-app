# Upgrade to SDK 0.77.0

The codemod moves named imports of `searchVariable`, `choiceVariable`, and
`multiChoiceVariable` to their new filter exports in
`@altertable/data-app/contract`. It keeps local names so existing references
still point at the imported binding.

Move each filter declaration to the operations that use it. Replace
`defineDataView()` and `defineTimeView()` with `defineView()`. Move validation
for app-specific inputs into the operation and check the filter defaults,
URL keys, custom mappings, and comparison behavior. In particular, review
search length limits and the date picker policy.

Give widgets their own queries when they display different results. Verify
that totals still cover the intended rows and that filters refresh the
right widgets. Load data needed by the toolbar, story, or export with
`summaryViews` where required.

See the [operation and filter migration diff](https://github.com/altertable-ai/data-app/commit/4f9fcd5ac72755805bf60de78e45e6cf2c4855a8).
