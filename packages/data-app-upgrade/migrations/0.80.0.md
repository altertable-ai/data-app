# Upgrade to SDK 0.80.0

Runtime URL keys now start with `_`: `_view`, `_about`, `_tab`, `_present`,
`_step`, and `_details`. Filter keys can no longer start with `_`. Rename any
filter key that does, then update saved links that use the old key.

Links with the previous unprefixed keys still open as before, and the app
rewrites them to the prefixed keys on its next URL write. Update any host or
script that builds app links, such as `?present=1&step=<id>`, to write the
prefixed keys. The unprefixed keys stay reserved for filters during this
transition.

The following additions need no change. Pass `{ id }` as the second argument to
`view.content()` to make that content addressable with `?_widget=<id>`, and use
`_theme=light` or `_theme=dark` to set that widget's theme. Hosts can subscribe
to `onWidgetCaptureChange` to know when a focused widget is ready to capture.

This release has no automatic source edits.
