# Upgrade to SDK 0.78.0

Local apps pass their shared declaration to `serveLocalApp({ page, app: dataApp })`.
Register browser-safe operations with `dataApp.defineOperations()` and use
`operations.createDataClient()`. Install `installLocalQueryLakehouse()` before
mounting the app. Move operation code that uses server-only credentials out of
the browser entry before using the new client.

Embedded hosts now render page actions. Subscribe through `onActionsChange`
and invoke actions through `runAction()` on the bridge. Move custom toolbar
and footer actions into the host where needed, and check export, story,
and annotation behavior in an embedded preview.

These changes span the server, browser, and host. This release has no
automatic source edits.

See the [release changes](https://github.com/altertable-ai/data-app/compare/v0.77.0...v0.78.0).
