# Build Altertable data apps

Use [app authoring](docs/app-authoring.md) for SDK mechanics and available starters.
The calling app brief chooses the use case, content structure,
and starter; examples demonstrate APIs rather than a required app layout.
For an existing app, start from its current source. Open another guide only when the
task needs a pattern that source does not cover. Search [REFERENCE.md](REFERENCE.md) for the exact export or prop.

## Contribute to this repository

Read [Contributing](CONTRIBUTING.md) before changing packages or contributor
tooling. App authoring guides teach agents how to build apps with the SDK.
Keep reusable behavior in components, defaults, types, and tests. Add authoring
documentation only when an app author must make a decision or take an action;
do not restate patterns already handled by the SDK.
